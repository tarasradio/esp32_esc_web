# Прошивка на ESP-32S для управления ботом для боев
Используется:
- регулятор: BLHeli_S 4-in-1 ESC;
- контроллер: NodeMCU-32s (38 pin).

Назначение выводов:
```
#define MOTOR_L_PIN   25 // Левый мотор
#define MOTOR_R_PIN   26 // Правый мотор
#define MOTOR_S_PIN   27 // Мотор спиннера
#define LED_RED_PIN   14 // Индикация потери сигнала
#define LED_BLUE_PIN  12 // Индикация сигнала
```

Для настройки максимальной скорости (границы):
```
#define US_MIN 1376   // полный назад (можно до 1000)
#define US_MAX 1600   // полный вперёд (можно до 2000)
```
